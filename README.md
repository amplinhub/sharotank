# Шаротанк 5T-L

Retro-futuristic voxel tank game: smash robots and buildings across Chinese-style city districts.

Играть: https://amplinhub.github.io/sharotank/

Версия v30.9 игры [Шаротанк Онлайн](https://github.com/amplinhub/sharotank-online) без игры с другом: кампания, «Профиль» (рейтинг, друзья, чат, лом, медали). Собирается там командой `npm run build` (`dist-solo/index.html`). Three.js. Управление: WASD — движение, мышь — прицел и огонь, средняя кнопка — захват цели. На телефоне — два стика.
