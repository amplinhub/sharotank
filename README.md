# Шаротанк 5T-L

Retro-futuristic voxel tank game: smash robots and buildings across Chinese-style city districts.

Играть: https://amplinhub.github.io/sharotank/

Браузерный прототип на Three.js. Управление: WASD — движение, мышь — прицел и огонь, средняя кнопка — захват цели. На телефоне — два стика.
