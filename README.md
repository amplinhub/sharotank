# Шаротанк 5T-L

Retro-futuristic voxel tank game: smash robots and buildings across Chinese-style city districts.

Играть: https://amplinhub.github.io/sharotank/

Офлайн-версия (v29.5) игры [Шаротанк Онлайн](https://github.com/amplinhub/sharotank-online): одиночная кампания, без игры с другом, «Водителей» и меню отладки. Собирается там командой `npm run build` (`dist-offline/index.html`). Three.js. Управление: WASD — движение, мышь — прицел и огонь, средняя кнопка — захват цели. На телефоне — два стика.
